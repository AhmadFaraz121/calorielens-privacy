# Calorie Lens — privacy policy

Public hosting for the Calorie Lens privacy policy, required by Google Play.

**Live:** https://ahmadfaraz121.github.io/calorielens-privacy/

The canonical source is `PRIVACY_POLICY.md` in the (private) app repository. When that
changes, update `index.html` here to match and bump the date in both.

The Play **Data safety** form must agree with this page. A mismatch is grounds for
rejection or removal, so change the form whenever you change the policy.
